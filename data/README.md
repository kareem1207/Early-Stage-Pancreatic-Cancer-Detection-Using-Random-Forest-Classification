# Data

## Source (target dataset)

This project targets the **"Urinary biomarkers for pancreatic cancer"** dataset
by Debernardi et al. (2020), *PLOS Medicine*, DOI:
[10.1371/journal.pmed.1003489](https://doi.org/10.1371/journal.pmed.1003489).
It is publicly mirrored on Kaggle as
["Urinary biomarkers for pancreatic cancer"](https://www.kaggle.com/datasets/johnjdavisiv/urinary-biomarkers-for-pancreatic-cancer)
(license: CC BY 4.0, per the original publication).

The dataset contains urinary biomarker measurements for three diagnosis groups:

| `diagnosis` | Meaning |
|---|---|
| `1` | Control / healthy |
| `2` | Benign hepatobiliary disease (non-cancerous) |
| `3` | Pancreatic ductal adenocarcinoma (PDAC) |

Original columns: `sample_id`, `patient_cohort`, `sample_origin`, `age`, `sex`,
`diagnosis`, `stage`, `benign_sample_diagnosis`, `plasma_CA19_9`, `creatinine`,
`LYVE1`, `REG1B`, `TFF1`, `REG1A`.

## ⚠️ Assumption flagged: this repo ships a SYNTHETIC placeholder dataset

This sandboxed environment has no outbound access to Kaggle/UCI to download the
real CSV. To keep the pipeline runnable end-to-end, `data/raw/urinary_biomarkers.csv`
was generated by `src/data_loader.py::generate_synthetic_dataset()` to **match the
real dataset's schema, value ranges, and class-imbalance pattern** (control ≈
benign > PDAC), using distributions informed by the published paper (e.g. PDAC
samples tend to have higher CA19-9, LYVE1, REG1B, TFF1).

**Before your final submission, replace the synthetic file with the real one:**

1. Download `Urinary_biomarkers_for_pancreatic_cancer.csv` from the Kaggle link above.
2. Save it as `data/raw/urinary_biomarkers.csv` (same filename, same columns).
3. Re-run `python src/train.py` — the pipeline itself does not change; only the
   numbers/plots will update to reflect real data.

If the real dataset uses slightly different column names, adjust the
`COLUMN_MAP` / `TARGET_COLUMN` constants at the top of `src/data_loader.py`.

## Files

- `raw/urinary_biomarkers.csv` — synthetic placeholder, real-dataset schema (see above)
- `processed/train.csv`, `processed/test.csv` — cleaned, encoded, split output of `src/preprocess.py`
